# Moss / Ink

An original living dither garden and reusable visual system, inspired by printmaking, halftone shaders, field guides and quiet simulation interfaces.

## Design system

- **Paper:** `#AAA79D`
- **Lift:** `#C7C3B9`
- **Ash:** `#5D5A53`
- **Ink:** `#1A1917`
- Four material densities: dot, line, crosshatch and checker.
- Tiny monospaced interface labels, one expressive serif scale.
- Full-bleed scenes with micro-chrome at the edges.
- Calm phase-offset motion. One saturated signal color is allowed when an app needs state.

Open the arrow control in the build for the full adoption guide.

Everything is static and local-first. No network requests, analytics, cookies, storage, accounts or dependencies.
